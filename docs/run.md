# How to Run Aadhaar Sanket (Streamlit Version)

The project has been restored to the original Streamlit architecture.

## 1. Prerequisites
Ensure you have Python installed and your virtual environment is active.

```powershell
# Activate the virtual environment
.\.venv\Scripts\Activate
```

## 2. Install Dependencies
If you haven't recently, ensure all requirements are installed:

```powershell
pip install -r requirements.txt
```

## 3. Run the Application
Use the standard Streamlit command:

```powershell
streamlit run frontend/1_National_Overview.py
```

## 4. Access the Dashboard
Streamlit will automatically open your web browser, usually at:

👉 **[http://localhost:8501](http://localhost:8501)**

You can navigate to other pages using the Streamlit sidebar.
